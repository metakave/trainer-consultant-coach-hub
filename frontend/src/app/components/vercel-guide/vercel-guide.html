🚀 VERCEL & DATABASE DEPLOYMENT ARCHITECTURE

How to Deploy on Vercel Free Plan + Neon Postgres

This repository is 100% configured for 1-click Vercel Free Tier hosting and Serverless Node API execution paired with Neon / Vercel Postgres free tier database.

01

Push Code to GitHub

Commit your workspace files to GitHub or GitLab repository.

git init && git add . && git commit -m "Initial Experts Hub"
02

Import Project in Vercel

Log in to vercel.com, click "Add New Project" and select your GitHub repo. Vercel automatically detects `vercel.json`!

03

Provision Free Database (Neon / Vercel Postgres)

In your Vercel Project Dashboard, navigate to Storage ➔ Connect Database ➔ Neon Postgres (Free) or Vercel Postgres (Free). Click Create!

04

Set Environment Variable

Add POSTGRES_URL or DATABASE_URL in Vercel Project Settings ➔ Environment Variables.

DATABASE_URL="postgres://user:password@ep-sample.neon.tech/neondb?sslmode=require"

⚡ Architecture Highlights

  • ✅ Vercel Serverless Functions (`/api`): Executes the Node + Express scraping & profile APIs with 0 cost.
  • ✅ Angular 19 Frontend: Built to static assets and served on Vercel Edge CDN for ultra-fast global load times.
  • ✅ Automatic Cheerio Scraper Engine: Parses meta tags, OpenGraph images, and social channels on demand.
  • ✅ Neon Postgres Free Tier: Stores profile claims, client badges, and incoming corporate consultation leads without credit card requirement.
